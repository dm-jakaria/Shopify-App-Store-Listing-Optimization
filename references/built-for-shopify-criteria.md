# "Built for Shopify" Status & Compliance Reference

The **Built for Shopify** program is Shopify's premier quality badge awarded to apps that achieve the highest standards in design, performance, security, and merchant experience. Apps with this badge receive prominent UI badging, algorithmic boosts, and inclusion in curated App Store collections.

---

## 1. Core Qualification Pillars

To qualify for the "Built for Shopify" badge, an app must meet strict automated and manual review criteria across 4 pillars:

```
+-------------------------------------------------------------------+
|                     Built for Shopify Pillars                     |
+-------------------------------------------------------------------+
  [Design & UX]         [Speed & Performance]   [Storefront Safety]   [Merchant Trust]
  - Polaris UI System   - <50ms Storefront Cost - Theme App Blocks    - High Ratings (>4.5)
  - Embedded App Bridge - Web Vitals (LCP, CLS) - No Liquid Clutter   - Low Churn/Uninstalls
```

---

## 2. Technical & Performance Requirements

| Standard | Benchmark Requirement | Listing & Strategic Impact |
| :--- | :--- | :--- |
| **Storefront Performance** | Maximum **50ms** storefront render impact. Zero degradation to Core Web Vitals (LCP, FID/INP, CLS). | Highlight "Zero impact on store page speed" in listing copy. |
| **Theme App Extensions** | Must integrate purely via Theme App Blocks and App Embeds (Online Store 2.0). | Merchants fear theme code pollution. Emphasize "No theme code editing required; clean uninstalls". |
| **Shopify Admin Experience** | Must be embedded using Shopify App Bridge and built with Polaris design components. | App looks and feels native to Shopify Admin, reducing onboarding confusion. |
| **Billing Integration** | Must use Shopify Billing API natively for all app subscriptions and one-time charges. | Clear, trusted checkout experience on merchant's existing Shopify bill. |

---

## 3. Merchant Experience & Support Standards

1. **Review Rating Threshold**:
   - Maintain an average rating of **4.5 stars or higher** with consistent review history.
2. **Support Response Time**:
   - Provide documented, responsive customer support channels (email, live chat) inside the partner dashboard and app admin.
3. **Frictionless Onboarding**:
   - Onboarding setup steps must be complete in under 5 minutes without mandatory developer intervention.

---

## 4. How to Leverage "Built for Shopify" in Listing Copy

When an app qualifies (or is built to these standards), highlight it strategically across the listing:

- **Tagline / Subtitle**: Integrate trust signals when characters permit.
- **Key Benefits**: Include a bullet: `**Native Shopify Admin:** Built with Polaris for an intuitive, seamless workflow inside your store.`
- **Visual Assets**: Show screenshots of the app embedded natively inside the Shopify Admin UI rather than standalone external web dashboards.
- **FAQ Section**: Directly reassure merchants:
  - *Q: Will this app slow down my storefront?*
  - *A: No. Built to official Shopify performance benchmarks with zero storefront script bloat.*
  - *Q: What happens if I uninstall the app?*
  - *A: Because we use Theme App Extensions, uninstalling removes 100% of app assets instantly with zero orphaned theme code.*
