# Contributing to Shopify App Listing Optimization Skill

We welcome contributions, template suggestions, and translation improvements from the Shopify developer community!

---

## 🔒 Branch Protection & Submission Rules

To protect the integrity of the live repository:
- **Direct commits to `main` are disabled** for external contributors.
- All contributions must follow the standard **Fork & Pull Request (PR)** workflow.
- No code or documentation changes will go live without manual review and approval by [JAKARIA](https://github.com/dm-jakaria).

---

## 🛠️ How to Contribute

1. **Fork the Repository**:
   Click the **Fork** button at the top right of this GitHub page to create your own copy.

2. **Clone your Fork locally**:
   ```bash
   git clone https://github.com/YOUR_GITHUB_USERNAME/Shopify-App-Store-Listing-Optimization.git
   ```

3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/NewTemplateOrGuide
   ```

4. **Make Your Improvements**:
   - Ensure all character limits comply with official Shopify standards (30 chars Name, 62 chars Subtitle, 100 chars Intro, 500 chars Details, 5x80 chars Features).
   - Ensure copy remains strictly outcome-focused and merchant-centric.
   - Do NOT include proprietary API keys, secrets, or sensitive merchant data.

5. **Commit and Push**:
   ```bash
   git commit -m "docs: add B2B wholesale screenshot storyboard template"
   git push origin feature/NewTemplateOrGuide
   ```

6. **Open a Pull Request**:
   Navigate to the original repository and open a Pull Request against `main`. Provide a clear description of the enhancement.

Thank you for helping empower the Shopify app developer community!
